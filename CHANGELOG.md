# Changelog

## 1.0.0 (2026-11-26)

First release of Deskmate, based on PhoneBox 0.9.24.

- One download: DeskmateAgent.exe installs itself, and carries the phone app, adb and the PawnIO sensor driver.
- CPU temperature through a built-in sensor reader (one admin prompt to set up); no LibreHardwareMonitor needed.
- Discord page with voice controls and favourite servers; AI quota bars; VALORANT page; red Mute LED on the Shortcuts page.
- Windows only. No auto-updates from the internet: a new exe updates the PC and then the phone over USB.
